# Дорожка — журнал тренера по плаванию

Сервис для одного тренера: расписание по дням и неделям, типы занятий (грудничковое 30 мин, индивидуальное, сплит, мини-группа, группа — по 45 мин), отметка посещений, остаток и история занятий, оплаты с чеками по номеру телефона, заметки к тренировкам, напоминания тренеру в Telegram.

Работает на https://dorozhka.vercel.app.

## Как устроено

- `dorozhka.html` — всё приложение в одном файле. Режимы:
  - облако — Supabase, вход через Telegram-бота;
  - локальный сервер — `server/`, база SQLite на ноутбуке;
  - демо — данные в браузере.
- `shared/schedule.mjs` — логика напоминаний и кнопок посещаемости. Её используют и сервер на ноутбуке, и облачная функция.
- `cloud/build.mjs` собирает сайт в `cloud/web/` и копирует `shared/schedule.mjs` в функцию.
- `cloud/supabase/` — миграции базы и функция `telegram`. Функция отвечает за напоминания каждую минуту (pg_cron), webhook бота и вход через бота.

## Сборка и выкладка

```bash
npm install
node cloud/build.mjs
npx supabase functions deploy telegram --no-verify-jwt --workdir cloud
npx vercel deploy --prod --yes --cwd cloud/web
```

### Миграции

Каждую новую миграцию применяйте так:

```bash
npx supabase db query --linked --workdir cloud -f supabase/migrations/<файл>.sql
```

Затем запишите её версию в `supabase_migrations.schema_migrations`.

В этом проекте Supabase новые таблицы не получают прав для API-ролей автоматически. Поэтому выдавайте `grant` в каждой миграции.

## Локальная версия

```bash
node server/server.mjs
```

Сервер запускается на порту 4318. Не запускайте его, пока бот подключён к облаку, иначе напоминания будут приходить дважды.
